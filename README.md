One original fortune-cookie line for a software developer: the legacy code you curse was written by someone in a hurry, just like you are now. `main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, with a gate that checks it is one non-blank line of 1–120 UTF-8 characters with no control characters and verifies the written file round-trips exactly.
