A single fortune-cookie line for developers, written for the make.fun bounty of the same name. It is about legacy code and the hurry it was written in — the kind of thing a tired senior engineer nods at:

> The legacy code you curse was written by someone in a hurry, just like you are now.

`main.py` keeps the line, checks it against the gate (one line, 1–120 characters, plain UTF-8, no control characters), writes it to `/output/entry.txt`, and reads the file back to confirm the bytes match exactly. Python 3.13, standard library only, no network.
